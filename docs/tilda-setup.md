# Игра на Tilda + таблица Google: пошаговая настройка

Инструкция для человека, который впервые запускает игру на Tilda и подключает Google Sheets. Терминал нужен максимум на одну команду; есть вариант совсем без него.

## Как это устроено

| Что | Где живёт | Что делает |
| --- | --- | --- |
| **Игра** (три блока `01-…`, `02-…`, `03-…`) | страница Tilda | то, что видят студенты и ведущий |
| **Скрипт** `integrations/google-sheets/Code.gs` | Apps Script внутри вашей Google-таблицы | принимает данные от игры и пишет их в таблицу |
| **Адрес веб-приложения** (оканчивается на `/exec`) | в блоке 1 в `data-sync-url=""` | по нему игра находит скрипт |
| **Таблица** | ваш Google Drive | хранит всё; видите её только вы |
| **Пароль ведущего** | свойства скрипта (в таблице не виден) | открывает на странице игры панель «Facilitator» |

Игра и таблица связаны только адресом `/exec`. Студенты ссылку на таблицу не получают.

**Что понадобится:** аккаунт Google; аккаунт Tilda с тарифом, где доступен блок «HTML-код» (T123). По моим сведениям, на бесплатном тарифе вставка своего HTML недоступна: проверьте в настройках своего тарифа до начала.

## Часть A. Таблица и скрипт Google (один раз, 10 минут)

Подробный вариант с разбором ошибок: [integrations/google-sheets/README.md](../integrations/google-sheets/README.md). Коротко:

1. https://sheets.google.com → **Blank spreadsheet** → назовите «One Market First».
2. В таблице: **Extensions → Apps Script**. Откроется редактор.
3. Возьмите код скрипта и вставьте его в редактор целиком, заменив всё, что там было:
   - **Вариант 1 (без терминала).** Откройте на GitHub файл `integrations/google-sheets/Code.gs`, нажмите кнопку **Copy raw file** (иконка с двумя квадратами справа над кодом). В редакторе: **Cmd+A** (на Windows Ctrl+A), **Cmd+V**.
   - **Вариант 2 (терминал).** В папке проекта: `pbcopy < integrations/google-sheets/Code.gs` (Mac). Затем **Cmd+A**, **Cmd+V** в редакторе.
4. **Cmd+S** (сохранить). Над кодом рядом с «Debug» должен появиться список функций вместо «No functions».
5. Вернитесь в таблицу, обновите страницу (**Cmd+R**). Через несколько секунд в меню появится **One Market First**.
   - Если не появилось: в редакторе выберите функцию **onOpen** в списке над кодом и нажмите **Run**, выдайте доступ, затем снова обновите таблицу. Скрипт должен быть создан именно через **Extensions → Apps Script** этой таблицы.
6. **One Market First → Set up the game (sheets + password)**. Выдайте доступ: **Continue → ваш аккаунт → Advanced → Go to Untitled project (unsafe) → Allow**. Это предупреждение Google для любого непроверенного скрипта; скрипт ваш, его код открыт.
7. В окне введите **пароль ведущего** (от 8 символов) и **OK**. Запишите его. Появятся листы Overview, Team 1–4, Scores, Players, Settings, Decisions, Notes.
8. В редакторе Apps Script: **Deploy → New deployment**. Нажмите шестерёнку рядом с «Select type» → **Web app**. Поля: **Execute as: Me**, **Who has access: Anyone**. **Deploy**, при запросе снова разрешите доступ.
9. Нажмите **Copy** рядом с **Web app URL**. Он выглядит так: `https://script.google.com/macros/s/AKfy…/exec`. Откройте его в новой вкладке: должно быть `{"ok":true,"service":"one-market-first","version":3}`. Если открылась страница входа в Google, вы выбрали не «Anyone»: создайте развёртывание заново.

## Часть B. Какой код вставлять в Tilda

В Tilda вставляются **три файла из корня проекта**, в таком порядке сверху вниз:

1. `01-t123-html-css.txt` — стили, разметка, данные игры, **и здесь нужно прописать адрес из части A**;
2. `02-t123-game-engine.txt` — правила;
3. `03-t123-game-interface.txt` — интерфейс.

В каждый блок копируется **весь** файл целиком. Файлы создаёт `node scripts/build.mjs`, вручную их править не нужно, кроме адреса в блоке 1.

### Как прописать адрес `/exec` в блок 1 (выберите один способ)

**Способ 1 — скриптом (рекомендую).** В папке проекта (нужен Node.js 20+, `node --version`):

```bash
node scripts/build.mjs --sync-url=https://script.google.com/macros/s/ВАШ_АДРЕС/exec
```

Команда создаёт папку `dist/` с тремя готовыми файлами, где адрес уже вписан. Вставляйте в Tilda файлы **из `dist/`**. Файлы в корне проекта остаются без адреса; на сервер GitHub `dist/` не попадает.

**Способ 2 — вручную.** Откройте `01-t123-html-css.txt` в любом редакторе. В самом начале найдите строку, которая начинается с `<section id="one-market-first"` и заканчивается `data-sync-url="">`. Между кавычками вставьте адрес так, чтобы получилось:

```html
<section id="one-market-first" lang="en" aria-label="Revolut — One Market First" data-sync-url="https://script.google.com/macros/s/AKfy…/exec">
```

Адрес вставляется **целиком, без пробелов и переносов**. Остальное в файле не меняйте. Блоки 2 и 3 копируйте как есть.

**Способ 3 — копированием из терминала (Mac).** Подставляет адрес и сразу кладёт результат в буфер обмена:

```bash
sed 's|data-sync-url=""|data-sync-url="ВАШ_АДРЕС"|' 01-t123-html-css.txt | pbcopy
```

Для блоков 2 и 3: `pbcopy < 02-t123-game-engine.txt`, затем `pbcopy < 03-t123-game-interface.txt`.

Файлы можно скачать и без терминала: откройте файл на GitHub → **Copy raw file** (или **Download raw file**).

## Часть C. Страница в Tilda

1. В Tilda создайте или откройте проект и **новую пустую страницу** для игры.
2. В библиотеке блоков найдите блок **«HTML-код» (T123)**: раздел «Другое». Добавьте его на страницу **три раза**. Не используйте Zero Block.
3. В первом блоке нажмите **Контент**, удалите содержимое поля, вставьте целиком файл **1** (с адресом), нажмите **Сохранить и закрыть**.
4. Во втором блоке то же самое с файлом **2**, в третьем — с файлом **3**. Порядок блоков на странице: 1, 2, 3 сверху вниз.
5. **Настройки страницы**: не нужны лишние блоки и меню Tilda на этой странице, чтобы ничего не мешало. При желании скройте шапку и подвал.
6. **Опубликуйте страницу** (кнопка «Опубликовать») и откройте её по адресу сайта. Проверяйте только на опубликованной странице: предпросмотр в редакторе Tilda не годится.

Если вы вставили блок 3 без блока 2, игра сообщит «A game block is missing…»: вставьте блоки по порядку.

## Часть D. Проверка (обязательно до занятия)

1. Откройте опубликованную страницу. Нажмите **Facilitator**, введите пароль, нажмите **Refresh now**: сверху должно быть «Connected». Если написано «This page has no Google Sheets address», адрес не попал в блок 1 (вернитесь к части B).
2. Откройте страницу ещё в одном окне как студент: **Join your team**, введите имя, ответьте на вопрос.
3. В окне ведущего: **Add demo players (test)** → **Form teams**. В окне студента появится номер команды; нажмите **I’m ready**.
4. Ведущий: выберите **right now** → **Start the game**. Если окно студента не открыло игру само, нажмите **Play on this device instead**.
5. Зафиксируйте решение R1. В таблице на листе вашей команды (`Team N`) должна появиться строка R1.
6. Ведущий: **Start a new game**: демо-игроки удалятся, копия таблицы сохранится в Drive. Без этого шага демо-игроки останутся на настоящем занятии.

## Часть E. Что делать при изменениях

| Что изменилось | Что сделать |
| --- | --- |
| Обновился `Code.gs` | Вставить новый код в Apps Script, сохранить; затем **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. Адрес `/exec` остаётся тем же. Без новой версии работает старый код. |
| Обновился код игры (`src/`) | `git pull`, затем `node scripts/build.mjs --sync-url=…`, заново вставить **все три** блока в Tilda и опубликовать. |
| Новое занятие | Ничего не вставлять: на панели ведущего **Start a new game**. |
| Забыли пароль | Меню таблицы **One Market First → Set facilitator password**. |

## Если что-то не работает

| Симптом | Причина и что делать |
| --- | --- |
| Меню **One Market First** не появилось | Скрипт создан не из этой таблицы или код не сохранён. См. часть A, шаг 5. |
| По адресу `/exec` страница входа Google | Развёртывание создано с доступом не «Anyone». Создайте новое развёртывание. |
| В панели «This page has no Google Sheets address» | В блок 1 не вписан адрес, или вставлена старая версия блока. |
| В панели «Wrong facilitator password» | Неверный пароль; новый задаётся в меню таблицы. |
| «The facilitator password is not set» | Не выполнен шаг 7 части A. |
| Игрок видит «The game has already started» | Он зашёл после старта. Начните новую игру или пусть к нему присоединится команда через капитана. |
| Игрок не может зайти: «That name is already taken» | Имя занято. Пусть добавит первую букву фамилии. |
| В таблице нет решений | Откройте страницу игры, под игроком, и посмотрите строку состояния под журналом решений: «Google Sheets: … waiting to be sent» значит, что связь не прошла. Проверьте адрес и доступ «Anyone». |
| Игра на странице не появилась | Блоки вставлены не в том порядке или вставлены не целиком. |

## Безопасность

- Игроки таблицу и её ссылку не видят: в странице только адрес `/exec`.
- Читать список игроков и все команды можно только с паролем ведущего. Игрок видит и пишет данные только своей команды.
- Адрес `/exec` виден в коде страницы. Присоединиться к игре может любой, кто его знает, до тех пор, пока вы не нажмёте **Start the game**. Следите за списком игроков на панели перед **Form teams**.
- Не показывайте студентам лист **Players**: в нём секретные пропуска игроков.
- После занятия можно отозвать развёртывание: **Deploy → Manage deployments → Archive**.
