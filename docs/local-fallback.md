# Запасной вариант: провести занятие без Google, с ноутбука ведущего

Если Google-таблица или Tilda не заработали, игру можно провести с одного ноутбука. Всё то же самое (вход игроков, случайные команды, старт, листы команд, оценки), только «таблица» живёт на вашем ноутбуке, а студенты открывают игру по адресу в локальной сети.

**Важно:**
- Это **не Tilda**. Студенты открывают страницу с вашего ноутбука, а не с вашего сайта.
- Все устройства (ваш ноутбук и телефоны/ноутбуки студентов) должны быть **в одной сети Wi-Fi**.
- Пока занятие идёт, ноутбук должен работать и не засыпать.

## Запуск

Нужен Node.js 20 и новее (`node --version`). Один раз скачайте проект (если его ещё нет):

```bash
git clone https://github.com/danilsushko104-commits/Strategy-game.git
cd Strategy-game
git checkout claude/lucid-wozniak-rcrpub
```

Перед каждым занятием (обновление и запуск):

```bash
cd /путь/к/Strategy-game
git pull origin claude/lucid-wozniak-rcrpub
node scripts/build.mjs
node scripts/serve.mjs --lan
```

В терминале появятся адреса. Нужен тот, что с пометкой `(same Wi-Fi)`, например `http://192.168.1.25:8080/`. Именно его вы даёте студентам (на проектор, в чат, QR-кодом). Окно терминала **не закрывайте**: пока оно открыто, игра работает. Остановка: Ctrl+C.

Пароль ведущего по умолчанию — `facilitator1`. Свой пароль: `node scripts/serve.mjs --lan --password=мой_пароль`.

Mac при первом запуске может спросить, разрешить ли Node принимать входящие подключения: нажмите **Allow**. Если вместо этого студенты не могут открыть адрес, проверьте в «Системные настройки → Сеть → Межсетевой экран», что Node разрешён.

## Ход занятия

Тот же, что и с Google ([integrations/google-sheets/README.md](../integrations/google-sheets/README.md), раздел «Как провести занятие»):

1. Студенты открывают адрес `http://…:8080/`, нажимают **Join your team**, вводят имя и отвечают, иностранный ли они студент.
2. Вы на своём ноутбуке открываете `http://localhost:8080/` → **Facilitator** → пароль → **Refresh now** → **Form teams** → дождитесь **I’m ready** → выберите время и **Start the game**.
3. Оценки экспертов: **Strategy and hearing score sheets**, затем **Send scores to Google Sheets** (в локальном режиме отправка идёт в локальную таблицу).

## Где смотреть «таблицу»

Откройте на своём ноутбуке http://localhost:8080/sheets/view. Это те же листы, что и в Google, в том же порядке: `Overview`, `Team 1 … 4`, `Scores`, `Players`, `Settings`, `Decisions`, `Notes`. Страница обновляется каждые 5 секунд. Показаны ячейки с буквами столбцов, как в Google Sheets (решение раунда R1 команды — строка 4, колонки A–N).

**Не показывайте эту страницу студентам** (в `Players` лежат секретные пропуска игроков, а студенты могли бы увидеть чужие решения). Она открывается только по `localhost` на вашем ноутбуке; но если вы подключаете ноутбук к проектору, не выводите её на экран.

## Как получить данные в Excel / Google Sheets

На странице `/sheets/view` у каждого листа есть ссылка **download CSV**. Скачайте нужные листы (`Team 1 … 4`, `Overview`, `Scores`, `Decisions`) и откройте в Excel или загрузите в Google Sheets: **File → Import → Upload**. Файлы в UTF-8 с BOM: кириллица и «Ü» отображаются верно.

Те же файлы по прямому адресу: `http://localhost:8080/sheets/export?sheet=Team%201`.

## Где лежат данные и как их не потерять

- Данные хранятся в файле `local-data/sheets.json` внутри папки проекта и сохраняются после каждой записи. Если сервер остановить и запустить заново, игроки, команды и решения остаются. Продолжить занятие можно после перезапуска ноутбука.
- **Сделайте копию этого файла** после занятия (и по ходу, если занятие длинное): `cp local-data/sheets.json ~/sheets-backup.json`. Чтобы вернуть данные, положите копию обратно на то же место при остановленном сервере.
- Файл содержит секретные пропуска игроков: не отправляйте его студентам. В Git он не попадает (папка исключена).
- Начать с нуля: на панели ведущего **Start a new game** (в локальном режиме «копия таблицы» создаётся только в памяти, поэтому сначала скачайте CSV) или остановите сервер и удалите `local-data/sheets.json`.
- Хотите вообще не сохранять данные на диск: `node scripts/serve.mjs --lan --data=none`.

## Ограничения запасного варианта

- Работает только по сети: если Wi-Fi не пускает устройства друг к другу (так бывает в учебных и гостевых сетях, «изоляция клиентов»), студенты не откроют адрес. Тогда раздайте интернет с телефона (режим модема) и подключите к нему ноутбук и студентов.
- Адрес выглядит как `http://`, а не `https://`. Игра в этом случае работает, но часть возможностей браузера (блокировки между вкладками, постоянное хранение) недоступна, и игра использует запасные способы. Для занятия это незаметно.
- Если ноутбук ведущего выключится, игра остановится для всех; после запуска сервера студенты обновляют страницу, и их игра продолжается из сохранённого файла.
- Данные на одном ноутбуке: резервной копии нет, кроме той, что вы сделали сами.
- Переноса в Google «в один клик» нет: данные можно перенести только через CSV (разд. выше).

## Быстрая проверка до занятия (5 минут)

1. Запустите сервер с `--lan`, откройте на телефоне адрес из строки `(same Wi-Fi)`.
2. На телефоне **Join your team**, введите имя.
3. На ноутбуке: `http://localhost:8080/` → **Facilitator** → пароль → **Refresh now**: на панели виден игрок с телефона.
4. **Add demo players (test)** → **Form teams** → **Start the game** (right now). Откройте игру на телефоне (или **Play on this device instead**).
5. Зафиксируйте R1 на телефоне и убедитесь, что на `/sheets/view` в листе вашей команды появилась строка.
6. **Start a new game**: демо-игроки удалятся.
