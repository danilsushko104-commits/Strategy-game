# Запись решений в Google Sheets

Каждое зафиксированное решение команды дополнительно отправляется в вашу Google-таблицу. Игра работает и без неё: решения сначала сохраняются в браузере, а при обрыве связи отправка повторяется сама.

## Подключение (около 10 минут)

1. Создайте новую Google-таблицу. Откройте **Расширения → Apps Script**.
2. Удалите содержимое файла `Code.gs` и вставьте весь текст из [Code.gs](Code.gs). Нажмите **Сохранить**.
3. Нажмите **Начать развёртывание → Новое развёртывание**, тип **Веб-приложение**:
   - «Выполнять как» — **Я** (ваш аккаунт);
   - «У кого есть доступ» — **Все**.
   Нажмите **Развернуть** и разрешите доступ (при первом запуске Google покажет предупреждение: **Дополнительно → Перейти в проект**).
4. Скопируйте **URL веб-приложения** (он заканчивается на `/exec`). Откройте его в браузере: должен появиться ответ `{"ok":true,"service":"one-market-first","version":1}`.
5. В блоке Tilda с игрой найдите в самом начале `data-sync-url=""` и вставьте URL между кавычками:
   `data-sync-url="https://script.google.com/macros/s/…/exec"`.
   Тот же адрес можно задать при сборке в `src/template.html`.
6. По желанию: обновите страницу таблицы, выберите меню **One Market First → Create overview sheet**. Появится лист `Overview`: введите в `B1` код комнаты, и таблица покажет выбор каждого стола по раундам и остаток кредитов.

> Если вы позже измените `Code.gs`, создайте **новую версию** развёртывания: **Начать развёртывание → Управление развёртываниями → ✏️ → Версия: Новая версия**. Иначе работает старый код.

## Проверка до занятия

1. Откройте страницу игры по её адресу в Tilda (по `https`).
2. **Facilitator → Create a new room** с временем старта R1 **на 5 минут раньше текущего** (Москва).
3. Войдите за стол 1 с этим кодом и зафиксируйте R1. Под кнопкой резервной копии должно появиться «Google Sheets: all 1 decision is saved», а в листе `Decisions` — новая строка.
4. Удалите тестовые строки (строка 1 с заголовками остаётся).

## Что записывается

Лист `Decisions`, по строке на решение:

| Столбец | Содержимое |
| --- | --- |
| `received_at` | Время приёма **по часам Google**, а не устройства команды |
| `room`, `team`, `market`, `round`, `choice`, `method`, `label`, `cost`, `credits` | Комната, стол, рынок, раунд, выбор, способ (`submitted` / `deadline` / `default`), название, цена, остаток кредитов |
| `client_time`, `sent_at`, `clock_offset_s` | Время фиксации на устройстве, время отправки, поправка часов устройства к серверу |
| `evidence`, `tradeoff` | Тексты «Evidence or assumption» и «Benefit and trade-off» |
| `chain`, `id`, `session`, `content` | Хэш цепочки решений, уникальный id, сессия, версия содержания игры |
| `flags` | `CONFLICT` и `CLOCK` (см. ниже) |

**Не отправляются:** заметки рабочих листов, Board Brief, практический режим. Для них остаётся скачиваемый JSON.

## Как таблица защищает от подделки

- Строки только добавляются. Исправить уже записанный раунд нельзя: переписанное решение создаёт **новую** строку с пометкой `CONFLICT`, а старая остаётся.
- `chain` зависит от всех предыдущих решений команды, поэтому изменение раннего раунда меняет и все следующие звенья.
- `CLOCK` помечает строку, если часы устройства расходились с Google больше чем на 2 минуты.
- Повторная отправка безопасна: одинаковые события не дублируются.
- Тексты студентов, начинающиеся с `=`, `+`, `-`, `@`, записываются как обычный текст, а не как формулы.

## Ограничения

- Адрес веб-приложения виден в коде страницы. Кто его знает, тот может отправить строку. Формат комнаты и стола проверяется, мусорные строки видны, но полной защиты нет. Для одного занятия этого достаточно; после занятия можно отозвать развёртывание.
- Скрипт отвечает на холодном старте за 1–3 секунды. Игра это учитывает и не блокирует интерфейс.
- Если браузер не может прочитать ответ Google, игра пишет «sent, but the browser cannot read the reply». Проверьте таблицу или нажмите **Send again**: дубликатов не будет.
- Скрипт и формулы листа `Overview` проверены автоматическими тестами с заглушками Google, но не на реальной таблице. Выполните проверку из раздела выше до занятия.
- Убедитесь, что `script.google.com` открывается из сети, в которой пройдёт занятие.
